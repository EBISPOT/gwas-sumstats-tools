GWAS Summary Statistic Formatting and Validation Tool

Cannot run from file:// — This tool must be served from an HTTP server, not opened directly as a file. Run python -m http.server in this folder and open http://localhost:8000 instead.
Browser requirement: This tool requires a modern browser with WebAssembly support (Google Chrome, Microsoft Edge, Firefox, or Safari 15.4+).
File size limit: For best performance, please process files that are smaller than 2 GB here.
